Check a Flyo booking before you send it

Paste the JSON you plan to send to the web check-in subscribe endpoint. The linter flags codeshare mix-ups, malformed codes, phone and email problems, and webhook settings that would cause a rejection or a silent failure later.

Subscribe payload

Runs on the server and nothing is stored. Press Ctrl+Enter to check.

Results

Paste a payload and select Check booking.

Unofficial tool built from Flyo's public documentation. It uses heuristics, so a clean result does not guarantee Flyo will accept the booking, and a warning is not always a failure. Use fake or test passenger data.
